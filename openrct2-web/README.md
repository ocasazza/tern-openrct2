# openrct2-web

OpenRCT2 v0.5.6 built for WebAssembly, served with the RCT2 data files, plus a JSON API that agents drive.

```
agent / curl ──POST /api──▶ server.py ◀──long-poll /bridge/next── page (bridge.js)
                                │                                      │ ccall orct2_agent_call
                       /rct2/* + www                        orct2-agent.js plugin (QuickJS)
```

- `bin/openrct2-web` serves the game (`--port 8737 --host 127.0.0.1 --rct2 DIR --www DIR`; `--rct2` defaults to the first line of `~/.config/openrct2/game-path`) and relays API calls to the open game page.
- `bin/orct2` is the CLI client. `ORCT2_URL` (default `http://127.0.0.1:8737`) selects the server for both `orct2` and your own curl calls.
- The page must be open (e.g. in the Tern browser block) for the API to answer; otherwise `POST /api` returns HTTP 503 `game_not_connected`.

## Envelope

Request: `{"v":"<verb>", ...}`. Success: `{"ok":true,"tick":N,"paused":bool, ...}`. Failure:
`{"ok":false,"tick":N,"paused":bool,"error":{"code":"...","message":"..."}}` (`orct2` exits 1 on `ok:false`).

| `error.code` | meaning |
|---|---|
| `invalid_args` | `error.missing` lists absent required args; `error.invalid` lists wrong types; `error.required` the full list |
| `unknown_action` / `unknown_verb` | `error.suggestions` / `error.verbs` |
| `action_failed` | the game rejected the action: `error.status`, `statusName`, `phase` (`query`/`execute`), `hint`; `query`/`executed` hold the raw results |
| `action_rejected`, `exception`, `not_ready`, `not_found` | engine threw, internal error, game not loaded, unknown id |
| `game_not_connected` (503), `timeout` (504) | server side: no page polling / no answer in 60 s |

## Verbs

Generated by `orct2 help --markdown`; `orct2 help` prints the same table.

| Verb | Arguments | Description | Example |
|---|---|---|---|
| `status` | `[include=["finance","messages","awards"]]` | Tick, pause/speed, date, park, scenario, climate, research, counts; include adds sections. | `orct2 status include='["finance"]'` |
| `rides` | `[id=N] [detail=true]` | List rides (or one); detail adds stations, ratings, breakdown. | `orct2 rides id=0 detail=true` |
| `guests` | `[sample=N] [id=N]` | Guest aggregates, thought histogram, N unhappiest guests; id returns one guest. | `orct2 guests sample=5` |
| `staff` |  | All staff with position, type, orders, costume. | `orct2 staff` |
| `map` | `[x=0 y=0 w=16 h=16]` | Tile window (tile coords, w*h<=1024): surface heights, ownership, elements. | `orct2 map x=60 y=60 w=8 h=8` |
| `objects` | `type=ride [installed=true] [offset=N limit=N]` | Loaded (or installed) objects with index/identifier; needed by ridecreate. | `orct2 objects type=ride` |
| `events` | `[since=N] [limit=N]` | Event ring buffer (day ticks, actions, breakdowns, crashes, park messages). | `orct2 events since=0 limit=20` |
| `act` | `<action> key=value... [--dry-run]` | Query then execute a game action; --dry-run only queries. Missing args -> invalid_args.missing. | `orct2 act ridesetprice ride=0 price=30 isPrimaryPrice=true --dry-run` |
| `actions` | `[action=<name>]` | List game actions with required args (or one). | `orct2 actions action=ridesetprice` |
| `park.open` |  | Open the park. | `orct2 park.open` |
| `park.close` |  | Close the park. | `orct2 park.close` |
| `park.fee` | `value=N` | Set park entrance fee (tenths of currency). | `orct2 park.fee value=100` |
| `ride.price` | `ride=N price=N [primary=true]` | Set a ride's primary (default) or secondary price. | `orct2 ride.price ride=0 price=30` |
| `ride.status` | `ride=N status=open\|closed\|testing\|simulating` | Set ride status. | `orct2 ride.status ride=0 status=open` |
| `staff.hire` | `staffType=handyman\|mechanic\|security\|entertainer [costumeIndex=N] [staffOrders=N]` | Hire staff at a random position. | `orct2 staff.hire staffType=mechanic` |
| `pause` | `[paused=true\|false]` | Set or (no arg) read the pause state. | `orct2 pause paused=true` |
| `speed` | `[speed=1..4]` | Set or (no arg) read the game speed. | `orct2 speed speed=2` |
| `advance` | `ticks=N` | Run N game ticks synchronously (fast-forward), then return status. | `orct2 advance ticks=400` |
| `load` | `path=<file> [asScenario=true]` | Load a park/scenario file from the wasm filesystem, then return status. | `orct2 load path="/RCT/Scenarios/Forest Frontiers.SC6" asScenario=true` |
| `save` | `filename=<name>` | Save to save/<name>.park in persistent storage. | `orct2 save filename=agent1` |
| `screenshot` | `OUT.png [filename=a.png zoom=0 rotation=0 x=N y=N width=1024 height=768]` | Render the map to a PNG file at OUT.png (x/y are map units; default map centre). | `orct2 screenshot /tmp/park.png zoom=1` |
| `eval` | `'<js>'` | Run JS in the plugin context; the JSON-able result is returned as value. | `orct2 eval 'park.cash'` |
| `call` | `'<json>'` | POST a raw request object. | `orct2 call '{"v":"status"}'` |
| `health` |  | GET /api/health (server + page connection). | `orct2 health` |
| `help` | `[--markdown]` | This listing. | `orct2 help` |

Notes:

- Money values (`cash`, `loan`, `value`, prices, fees, `cost`) are tenths of the currency unit.
- `act` takes the lowercase OpenRCT2 action name and its parameters exactly as the C++ `AcceptParameters` list them (`orct2 actions` lists all 80). Tile coordinates `x`/`y` are world units (tile * 32). An optional `flags` is accepted. The action is queried first; it is executed only if the query succeeds and `--dry-run`/`dryRun` is absent. `executed.ride` / `executed.peep` carry created ids.
- Actions are rejected with `statusName: "gamePaused"` while the game is paused; `orct2 pause paused=false` first.
- `status` always includes `park`, `scenario`, `climate`, `research`, `counts`; `include` adds `finance`, `messages`, `awards`.
- `events`: poll with `since=<previous next>`; `dropped:true` means older events fell out of the 500-entry ring.
- `screenshot` writes `<filename>` under `screenshot/` in the game's persistent store, returns it as `png_base64`, then deletes it; `orct2 screenshot OUT.png` decodes it to `OUT.png`. Without `x`/`y` it centres on the map; `full=true` renders the whole map (large).
- `load`/`advance`/`screenshot` are completed by `bridge.js` around the `orct2_load_park`, `orct2_advance` wasm exports; every other verb is handled by `orct2-agent.js`.

## Examples

```sh
orct2 status
orct2 act ridesetprice ride=0 price=30 isPrimaryPrice=true --dry-run
orct2 act ridesetprice ride=0 price=30 isPrimaryPrice=true
orct2 park.open
orct2 ride.status ride=0 status=open
orct2 advance ticks=4000
orct2 screenshot /tmp/park.png zoom=1
orct2 eval 'map.rides.length'
ORCT2_URL=http://10.0.0.5:8737 orct2 status
```

The same through curl:

```sh
URL=${ORCT2_URL:-http://127.0.0.1:8737}
curl -s $URL/api/health
curl -s -X POST $URL/api -d '{"v":"status"}'
curl -s -X POST $URL/api -d '{"v":"act","action":"ridesetprice","args":{"ride":0,"price":30,"isPrimaryPrice":true},"dryRun":true}'
curl -s -X POST $URL/api -d '{"v":"screenshot","filename":"a.png"}' | python3 -c 'import sys,json,base64;open("a.png","wb").write(base64.b64decode(json.load(sys.stdin)["png_base64"]))'
```

## HTTP endpoints

| Endpoint | |
|---|---|
| `GET /…` | static www with COOP/COEP/CORP headers (SharedArrayBuffer), `Cache-Control: no-cache` |
| `GET /rct2/manifest.json` | `{"version":"<hash>","files":["Data/ch.dat",…]}` over Data, ObjData, Tracks, Scenarios, Landscapes; 404 `{"error":"no_rct2_data"}` without `--rct2` |
| `GET /rct2/<relpath>` | file bytes (path traversal rejected) |
| `POST /api` | request JSON → response JSON (waits up to 60 s) |
| `GET /api/health` | `{"ok":true,"connected":bool,"version":"1"}`; `connected` = a page polled in the last 5 s |
| `GET /bridge/next`, `POST /bridge/result` | page side of the relay (25 s long-poll) |
